Deskripsi Singkat Proyek:
Proyek ini menganalisis data keberlanjutan kampus (energi, air, CO2, dan limbah) menggunakan dua bahasa pemrograman: C++ dan Python.
Tujuannya adalah membandingkan hasil analisis, klasifikasi, serta ringkasan data dari kedua bahasa.

Cara Menjalankan Program C++:
1. Masuk ke folder project
2. Compile file C++ : g++ main.cpp -o main.exe
3. Run program : .\main.exe
4. Cek hasil output

Cara Menjalankan Program Phyton:
1. Masuk ke folder project
2. Jalankan script (python main.py)
3. Cek hasil output

Perbandingan C++ dan Python:
1. Eksekusi Program
C++ harus melalui proses kompilasi sebelum dijalankan.
Python dapat langsung dijalankan tanpa kompilasi.
2. Analisis Data
C++ menghasilkan ringkasan dan klasifikasi melalui perhitungan manual.
Python memanfaatkan pustaka seperti pandas untuk ringkasan otomatis dan matplotlib untuk visualisasi.
3. Output
C++ menghasilkan file teks (.txt) dan CSV (.csv).
Python menghasilkan file teks, CSV, serta grafik dalam format gambar (.png).
4. Kelebihan dan Kekurangan
C++ unggul dalam kecepatan eksekusi dan efisiensi, namun kurang fleksibel untuk analisis kompleks.
Python lebih mudah digunakan, kaya fitur analisis dan visualisasi, tetapi relatif lebih lambat dibanding C++.
